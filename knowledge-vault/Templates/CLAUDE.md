# Templates

Note templates, one per note type. Copy the matching template when creating a note so structure stays consistent across contributors.

| Template | For |
|---|---|
| `Session Template` | a dated work-session note — carries **Author** and **Branch**, this vault is shared |
| `Project Template` | the living project overview |
| `Planning Template` | a feature plan with its ID legend |
| `Review Template` | a review and its findings |
| `Learning Template` | one atomic reusable finding |
| `Idea Template` | an idea at any maturity |
| `Skill Template` | a repo Claude Code skill |
| `Tracking Template` | an upstream subject tracker |
| `Tracking Entry Template` | one version or evaluation of a tracked subject |
| `Wave Plan Template` | an orchestration wave's plan under `Implementation/Waves/` — status, six-rules table, decisions, briefs |

Keep templates in step with the folder conventions in each `CLAUDE.md`. If you change what a folder requires, change its template in the same commit.
