## What was done

A new home, `lua/aineo/tabs/`, with `init.lua` as its one entry point and three files of its own. It requires no other aineo home: the form check of a session id and the write of the list are its own (`tab_list.lua`), as `lua/aineo/mcp/delivery.lua` holds its own id check.

| File | Holds |
|---|---|
| `init.lua` | `hold(tab, name)`, `let_go(tab)`, `held()`, `closed()`, `number(tab)`, `title(tab)`, `tabline()`, `draw_tabline()`, `keep_tabs(state_directory, folder, tab_list)`, `kept_tabs(state_directory, folder)`; the held tabs' name functions |
| `titles.lua` | the words of a title: `cut(name)` (24 display cells whole, else 23 and `…`, on a character's edge) and `buffer_tail(tab)` (`[No Name]` for none) |
| `tabline.lua` | the pure format of the line from entries `{ number, title, current }`: `%<number>T` regions, `TabLineSel`, `TabLine`, `TabLineFill`, `%` doubled |
| `tab_list.lua` | the folder's list as JSON `{ sessions, current }` in `<state>/aineo/claude-tabs/<SHA-256 of the folder>.json`, 0600, replaced whole through a file beside it, as `claude/session_ids.lua` writes the kept id |

Decisions inside the brief's gaps (each is the implementer's, for the reviewers to look at):

- **A `name()` that raises or gives no text** (nil, empty, not a string) counts as no name: the title then says the buffer's tail. The tab line is drawn on every redraw, and an error there would repeat on each one.
- **`number(tab)` of a tab page that does not exist** is nil, not an error; `title(tab)` of one is nil.
- **`kept_tabs()` raises nothing**, also for arguments that are no strings (it reads none), and reads at most 64 KiB (a longer file is none).
- **`keep_tabs()` raises an error naming the file** when the directory or the replacement fails, as `keep_session_id()` does, and removes its own half-written file. It writes the list it is given: an empty list or a bad id is written and read back as none.
- **A repeated id** in the list is not refused on reading: the brief's list of reasons for none does not name it.
- `closed()` gives the handles in ascending order of handle.
- The file's name ends in `.json`; the brief fixes the folder and the SHA-256 only.

The brief's facts were checked against `dev` `5942eba` and had not moved (`git grep -n "tabline\|TabClosed\|showtabline" -- lua plugin` prints nothing; `session_ids.lua` and `delivery.lua` unchanged since `1354cad`): no amendment (A256).

Modularity: `lua/aineo/tabs/` is not yet in the modularity skill's table of homes or its direction table (`tabs` requires no aineo home), which is an `ai/` change for the orchestrator. The deep-require check prints three lines for the home, each inside its own home: `init.lua` requiring `aineo.tabs.tab_list`, `aineo.tabs.tabline`, `aineo.tabs.titles`.

## Unit list

1. `hold` and `held`: the held tabs in the order of their places, not of their holding.
2. `let_go`.
3. `closed`: a tab `:tabclose` closed, once; a tab `:tabmove` moved, never; `held` leaves out a closed tab that `closed` still gives.
4. `number`: the place, held or not, following `:tabmove` and a close; nil for no tab.
5. `title`: held (`<number> <name>`, the number following `:tabmove`); not held (the buffer's tail of the tab's own current window, `[No Name]`); the cut (24 whole, 25, 60, multibyte, wide); a `name()` that gives nothing or raises.
6. `tabline`: titles, groups, click regions, `%` as written.
7. `draw_tabline`: sets while empty; leaves the user's; twice; `'showtabline'` untouched.
8. `keep_tabs` and `kept_tabs`: round trip; the file's name and mode; the last list kept; two folders; twenty files that are no list; no file; a directory in its place; a file grown past any list; arguments that are no paths; a replacement that fails (the list as it was, no file left behind); a directory that cannot be made.
