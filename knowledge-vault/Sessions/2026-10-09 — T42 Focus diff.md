## What was done

- **`lua/aineo/changes/init.lua`** (C15): the changes home's `show_diff(entry, diff)` — the select path, reached only from Enter (`open_entry()` → `show_last_diff()`, directly or at the next `SafeState` while textlock holds) — moves the cursor to the window the layout's `show_diff()` returned, and only when it returned one. When the diff is not shown (no room, or showing it raised), the cursor stays where it is. `nvim_set_current_win()` keeps Normal mode. Docstring updated with the code.
- **The layout is unchanged**: `require('aineo.layout').show_diff()` still puts the cursor back in the window it was in, for any caller.
- **`doc/aineo.txt`**, *aineo-changes*: the sentence “The cursor stays in the pane, so `j` and Enter step through the list” replaced: the cursor moves to the diff once it is shown, in the mode the user was in; it stays in the pane when the diff is not shown. The sentence the brief pointed at near line 119 (“The cursor stays in the window it was in”) is about `\pa`/`\pc` switching panes, not about diffs, and is left as it was.
- **Records**: D46 after D45; a dated note on C15; T42's row after T41. No D row said the cursor stays (D19 and D34 say only that Enter shows a diff), so no D row has a note.

## Where the move lives, and why

The callers of the layout's `show_diff()`: one, the closure the composition root hands the changes home (`plugin/aineo.lua`, `started_claude_terminal()`), called by one function, the changes home's `show_diff(entry, diff)`, which Enter alone reaches. No automatic path reaches it: a re-read of the pane (`pane_shown()`, `refresh_shown_pane()` on a save or `\pc`), `follow_changes_session()` from T39's `follow_session()`, a worktree list read again, and the watch only write the lists; a diff already shown stays as it was until Enter on its line again (`aineo.changes.diffs` rewrites a diff buffer only from that same Enter).

The move is the changes home's, not the layout's: the changes home knows the user selected an entry, the layout only places windows and cannot tell a selection from any other show. Rejected: the move inside the layout's `show_diff()` for every caller, which would move the cursor for any future automatic show; and a `focus` flag on `show_diff()`, a flag parameter selecting two behaviours (clean-code §2). No new require edge; `aineo.changes` still requires only `aineo.git`.
