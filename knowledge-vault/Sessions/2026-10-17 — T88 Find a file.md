# 2026-10-17 — T88 Find a file

**Author:** the repository's maintainer, with Claude — implementer agent (`neovim-lua-developer`, on Sonnet)
**Branch:** `feature/t88-find-file` · **Pull request:** into `dev`

A fuzzy file finder whose pick opens in the file column, editable and savable: `\f`, `<C-\>f`, `<Plug>(aineo-find)` and `:Aineo find` search the files under the tab's Claude working directory (the top of its repository when it is in one) with a third-party picker when one is installed, and through `vim.ui.select` otherwise. The pick opens as any file opened from the layout does; the file column's redirect (C9) is what routes it, so nothing about pickers reaches `layout/`.

## Design

- `lua/aineo/find/` (entry `init.lua`, requires no aineo home): `picker_in_use(setting)` names the picker a `find.picker` value takes, `find_file({ directory, picker })` starts the search. `pickers.lua` holds the four pickers (`snacks`: `require('snacks').picker.files({ cwd })`; `fzf-lua`: `files({ cwd })`; `telescope`: `require('telescope.builtin').find_files({ cwd })`; `mini.pick`: `builtin.files(nil, { source = { cwd } })`), each found by `pcall(require, …)`. `files.lua` lists the files of the fallback: what the `list_files` the composition root hands in gives (the git home's `list_files()`, F2), or, when none was handed in (no repository) or it fails (F6), a `vim.fs.dir` walk 8 directories deep that leaves `.git` out; both sorted by bytes and cut at 20000, told once when cut. With none installed, or the forced one missing (told once per search, as a warning), the files go to `vim.ui.select`; the choice opens in the window the search began in, and a refusal of `:edit` is told once, with an error (F5).
- `lua/aineo/entry/finding.lua` (composition root): the tab's Claude directory (`session_directory()`, else the editor's), the top of its repository through the git home's `find_repository()` (asynchronous, time-bounded), the picker from the resolved configuration, then `find_file()` — unless the cursor has left its window while the root was being found. `lua/aineo/entry/actions.lua`: `ACTIONS.find` finds the existing aineo tab (`existing_acting_tab()`, as `diff close` does) and makes none; with none it says `aineo: there is no aineo tab to find a file in`.
- `plugin/aineo.lua`: `find` in `SUBCOMMANDS`, `find = 'f'` in `PREFIX_KEYS`; the `<Plug>` mapping, the `\f` mapping and the `<C-\>f` twins follow from the existing loops.
- `lua/aineo/config/`: `find.picker`, default `'auto'`, validated against the five names. `lua/aineo/health.lua`: the key list, and a `Find a file` section that says which picker aineo will use, or warns when the forced one is missing.
- The routing of the pick to the file column is C9's redirect: a picker opens the file in a window of the tab, the layout's or the file column's (snacks.nvim with `:buffer`, mini.pick with `nvim_win_set_buf`, the fallback with `:edit`), and the redirect moves it from a layout window. The attack review of PR #262 measured that landing against the real snacks.nvim (20 starts) and the real mini.pick (2); the suite's fakes run `:edit` in the current window and model neither.

## Unit list

1. `find.picker` validates and defaults (config).
2. `picker_in_use()` takes the first installed picker for `auto`, the forced one when installed, none when the forced one is missing.
3. `find_file()` calls the picker with the folder as its working directory, per picker.
4. The fallback offers a repository's files, untracked ones in and ignored ones out.
5. The fallback walks a directory that is in no repository, leaving `.git` out.
6. The pick opens in the window the search began in.
7. A forced picker that is missing is told once; `auto` tells nothing.
8. An empty directory is told; a list longer than 20000 is cut and told.
9. `\f`, `<Plug>(aineo-find)` and `:Aineo find` ask the picker for the top of the repository, the folder outside one, the folder Claude started in whatever the editor's directory is.
10. The twin in Terminal and Insert mode; no aineo tab; a wrong setting; a cursor that left the window.
11. The pick lands in the file column modifiable, in Normal mode, written by `:w`, from Claude's terminal, the Report and Input.
12. Health says which picker is used.
13. The help, the README, D81.
