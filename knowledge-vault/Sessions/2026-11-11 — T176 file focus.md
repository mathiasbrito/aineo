## What

`<C-l>` in the explorer (the `\E` column and the `\e` pane) shows the file under the cursor as `l` does and turns the file focus on for the tab: the panes column (Report, Input and the pane shown, the run pane's stack included) closes and its cells go to the file column, the row being Claude | files | explorer, mirrored with Claude on the right. Every file opened while it lasts keeps the panes column closed. `<C-l>` again on any line, `:Aineo focus` or `<Plug>(aineo-focus)` bring the column back as it was. A key that shows a pane ends the focus. No default key outside the explorer.

- `lua/aineo/layout/init.lua` owns the state: `start_file_focus()`, `end_file_focus(arrangement)`, `is_file_focused()`; `M.open()` ends the focus; `is_laid_out()` lets the proportions, the explorer column and a file column opened meanwhile be kept while the panes column is closed on purpose; `size_focused_columns()` keeps Claude's and the explorer's widths and gives the file column the rest.
- `lua/aineo/explorer/home.lua`: `<C-l>` through the optional settings `is_file_focused` and `toggle_file_focus`; `lua/aineo/entry/explorer.lua` hands them (the tab found by its homes); `lua/aineo/entry/tab.lua` and `actions.lua`: `actions.focus` and `:Aineo focus`; `lua/aineo/entry/run_pane.lua`: an ended process is not discarded when the focus closes its window, and a process leaving does not end the focus.
- Registration: `plugin/aineo.lua` (`focus` after `zoom`), `lua/aineo/keys/init.lua` (the explorer row). Docs: `doc/aineo.txt` (File focus section, `:Aineo-focus`, `<Plug>(aineo-focus)`, the explorer key list, the prefix-keys sentence), `README.md`.

## Decisions (point 6 of the brief)

- Closing the file column, with the focus on, leaves it on; `:Aineo focus`, `<C-l>` in the explorer and any pane key bring the panes column back. Rejected: ending the focus when the file column closes.
- A zoom, of the panes column or full, ends as the focus starts (sizes not given back); `\z` with the focus on says the cursor is in none of the panes column's windows; `\Z` works on any window.
- `M.open()` ends the focus, so a session start, a resume and `setup()` re-applying the explorer column setting end it too; `\E`, a swap, a mirror and an editor resize keep it.
- An agent's run tool showing the stack ends the focus, as `\x` does.
- `<C-l>` closing the explorer *pane* closes the pane with the column; the cursor goes to the file.
