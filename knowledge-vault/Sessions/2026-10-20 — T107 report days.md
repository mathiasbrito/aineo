## What was done

- **Days.** `days.day_of(time)` reads `YYYY-MM-DD` from a record's time; `days.label_of_day(day, now)` gives `Today`, `Yesterday` or the weekday, date and month (`Mon 19 Oct`, English whatever the locale), with the year when it is not the year of `now`; `days.seconds_until_midnight(now)` goes through `os.time`, so a change of the clock for daylight saving is counted.
- **Rendering.** `render.render_records(records, names_file, context)` puts a separator line before each report whose day is not the day of the report before it (or of `context.previous_day`, for the first); a report with no readable day follows the report before it. The renderer returns the separators (`line`, `day`) and the last day beside the lines and colours.
- **Marks.** `day_separators.record()` marks each separator line with an extmark in the namespace `aineo_report_days`, in `AineoReportDay`, and keeps the day it starts and the last day; `name_days_as_of(buffer, now)` writes a separator again when its label changed; `clear()` runs when the Report is emptied (`:edit`).
- **Home.** A new report is rendered with its own time as `now` and the buffer's last day; the home then names every separator again as of that time. Records shown when the Report opens are named as of the clock, read only when there are records. A wait for the next local midnight (`schedule_after`, a `vim.defer_fn` timer when the environment gives none) names the days again and waits for the next; it is replaced at each draw and cancelled when the Report buffer is wiped.
- **Help.** A *Days* section under the Report (`aineo-report-days`), the group `AineoReportDay` (`hl-AineoReportDay`) in the colours list; README names the separators and the group.

## Decisions

- D96 and A524, read from the user's words and the orchestrator's rulings.
- **Drawn lines, not virtual lines** (A524 allowed either). A virtual line above the first line of a buffer is not shown while the window shows the buffer from its first line (measured on Neovim 0.12.5 in a child: `topfill` stays 0 and `screenpos()` puts line 1 on the first row), and the first report of a Report always starts a day. A drawn line is also the one thing path detection, double-click and `gx` already do not read.
- The clock is read for `now` only when there are records to show, because the suites' fake clocks hand a time to each call; a draw after a new report takes `now` from the report's own time.
- The help says nothing of what `gx` does on a separator: with no address on the line, Neovim's own `gx` falls back to the word under the cursor, as it does anywhere in the Report.
