## Context

**Goal.** T3 builds aineo's screen:
- C2 — the three windows, pinned against resizing, restored by `\o`;
- C9 — the file column, and the `BufWinEnter` redirect that fills it.

The entry point (T7) wires T3 to the prefix keys and to startup. Until then, nothing calls the layout.

## What was done

**Two files make up the home.**
- `lua/aineo/layout/init.lua` holds the state and the entry point.
- `lua/aineo/layout/columns.lua` reads `winlayout()`'s tree. It was split out in the fix round, and only `init.lua` requires it.

**The entry point is `require('aineo.layout')`:**

- **`open(arrangement)`**
  - **What it is handed:** `arrangement` is `{ claude, report, report_height }`.
  - **The first call builds the layout.**
    - Claude's buffer goes on the left, at half the columns (D4).
    - The Report goes above Input on the right, at `report_height` of that column (D13).
    - The cursor lands in Input.
  - **What happens to the tab.**
    - Its other windows close and their buffers stay loaded; floating windows are left alone.
    - A file shown in the current window stays, as the file column.
    - Called from a float, `open()` builds from the tab's first non-floating window.
  - **Input.**
    - It is made once, from the unnamed, empty startup buffer, or else as a new buffer.
    - It is named `aineo://input`, set to `nofile`, unlisted, `bufhidden=hide`, with no swap file.
    - It is made a scratch buffer again whenever it is shown, and made anew after `:bwipeout`.
  - **Later calls restore.** While any of the three windows exists, a call works in the layout's tab, moving there when another tab is current. It:
    - reopens only the closed windows, in their places;
    - shows each window its buffer (the handed ones);
    - puts the proportions back.
  - **Its arguments are checked** with `vim.validate`, and nothing changes before the check.
- **`focus(role, arrangement)`**
  - Moves the cursor to the Claude, Report or Input window.
  - When that window is gone, it reopens the layout first.
  - With the window present, it opens nothing and resizes nothing.
- **`input_buffer()`**: returns the Input buffer, for T6.

**Behind the entry point.**

- **Pins:** `'winfixwidth'` and `'winfixheight'` on the three windows.
- **Proportions:** put back after `WinClosed` (scheduled), `VimResized` and `TabEnter`, while the three windows exist.
- **The redirect.** A file (empty `'buftype'`) shown in one of the three windows schedules a move:
  - The file goes to the file column, which is created on first use and reused after. It is created right of Claude's column, or at the left of the tab when Claude's window is closed.
  - The window gets its buffer back.
  - The cursor lands in the file column, at the position the command gave it.
  - Under `'nohidden'`, a changed buffer in the file column is not abandoned: the file opens above it.
  - A window's own buffer is never taken for a file.
  - The move checks, when it runs, that the captured window is still one of the layout's and still shows the file.
- **The file column** is the set of columns between Claude's and the right one, in the deepest row of the layout's tab that holds the layout's windows. When one side is closed, the side that remains bounds it. With the file column open, the three columns take equal thirds (D6).
