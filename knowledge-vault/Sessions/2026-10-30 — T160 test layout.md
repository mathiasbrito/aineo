## What was done, and why

1. **Templates** (`template.lua`): a source template matched against a path binds its placeholders, a test template is rendered from them. `{path}` followed by `/` stands for no folder too, so a file at a unit's root pairs. A placeholder given twice must give the same text. A modified placeholder (`{path|_}`, `{x|-_}`) stands for one segment and makes its pair one-way. A placeholder with no binding renders as written, so a one-way pair used in reverse names no existing file instead of raising. The guards of A666 (3) are `problem()` and `pair_problem()`.
2. **Finding** (`finding.lua`, pure over a view of the repository's files): templates read from the unit root (`{unit}/` prefixed, the folder of the nearest manifest); candidates by rule order then shortest path; the text-match fallback asks one search for the strings `modules.lua` gives per language; the creating rule is the one marked `create`, else the first that matches; a new file gets the nearest existing test as `sibling` and the `companions` its sibling's folder has, in each new folder up to one that has it. A source that is itself a test is refused (an inline rule aside). The reverse uses two-way pairs only.
3. **Trust** (`trust.lua`): the user's pairs (pinned: the place whether the file exists or not) and the preset templates corrections fitted; the agent's statements; the presets of the file's extension whose markers the repository holds and the language's default, ranked by sources paired with tests; an agent statement pairing nothing while a preset pairs some goes after those presets. `assess()` gives the reply's pairs and contradictions.
4. **Store** (`store.lua`): JSON, one file per repository named by a hash of its main worktree's folder (`git rev-parse --git-common-dir`), under `stdpath('state')/aineo/test_layout/`, written beside and renamed.
5. **Presets** (`presets/`): the catalogue rows A668 names, one file per language, with discovery globs, markers (a file glob, or a file and a text it holds) and documentation links; C and C++ conventions marked `convention`.
6. **MCP**: the relay checks the call's shape and offers it to the editor that started Claude Code; the composition root binds `aineo.mcp`'s handler to `aineo.test_layout.declare()`, so `aineo.mcp` gains no edge to the new home. The tool is in `--allowedTools`; the system prompt's sentence names the preset ids, given by the entry.

## Decisions (the implementer's, within A665–A672)

- `{path}` stands for none when a `/` follows it (A666 (2) says "one or more"): without it a root-level file (`main.go`, `src/x.py` under `src/{path}/`) pairs with nothing. Reported as a spec reading.
- `{unit}` only begins a template, and every template is read as `{unit}/<template>`.
- Presets carry `extensions`: `{path}/{name}.{ext}` would otherwise pair a README.
- `describe()` and the health line name the origin as words: `python.pytest.flat, from the repository`.
- The test layout handler takes a call from any tab's Claude Code: the rules are per repository.
- The entry point reads `stdpath('state')` itself: A667's signatures leave no parameter for it.
