# References

Pointers to things that live outside this repository: external documentation, dashboards, tickets, regulations, vendor consoles.

## What belongs here

A reference is a **static pointer** — a URL and enough context to know why it matters and when to open it.

- Vendor, library and API documentation.
- Regulation and official sources.
- Dashboards, consoles, issue trackers, design files.

## What does not

- **Anything that changes and that we must stay current with** → `[[Tracking/CLAUDE|Tracking]]`. That is the distinction: `References/` is a static pointer, `Tracking/` is a living subject with a refresh protocol.
- Credentials of any kind. Ever. Reference the vault or secret manager, never the secret.

## Rules

- Record **why** the link matters here, not just what it is.
- Date anything version-sensitive, and note the version seen.
- Prune dead links when you find them.
