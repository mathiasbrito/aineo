# Attachments

Non-note files embedded or linked from notes: images, PDFs, exported diagrams, data blobs.

## Rules

- **Never explored, only followed.** Open a file here when a note you are reading links it (`![[file]]`) and you need it. Filesystem sweeps of the vault exclude this folder.
- **Every attachment must be linked from at least one note.** An unlinked file is unreachable and should be deleted.
- Descriptive filenames — `request-lifecycle-2026-09.png`, not `diagram2.png`.
- **Keep it light.** This folder is in git; large binaries bloat every clone forever. Prefer a committed source (a mermaid block, an SVG) over an exported raster. Anything above a couple of megabytes needs a reason.
- No screenshots containing credentials, tokens, or real customer data.
